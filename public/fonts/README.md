# Local Clash Display Font Instructions

To use your exact local font files across all devices and browsers:

1. Copy your Clash Display font file(s) (`.woff2`, `.woff`, `.otf`, or `.ttf`) into this `public/fonts/` directory.
   - Example: `public/fonts/ClashDisplay-Variable.ttf` or `ClashDisplay-Bold.otf`
2. Tell me the file name(s) you placed here, and I will link them directly via `next/font/local` in `layout.tsx` for optimal performance and zero-flash rendering!
